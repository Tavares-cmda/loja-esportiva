📋 Sobre o Projeto

Este sistema foi desenvolvido com HTML, CSS, Node.js, Express e SQLite para auxiliar no gerenciamento de uma loja esportiva. O projeto permite cadastrar clientes, controlar produtos, realizar vendas e acompanhar o estoque em tempo real.
