# Arena Sport 🏆

Loja esportiva online moderna desenvolvida para demonstrar e-commerce de artigos esportivos.

## Funcionalidades
- Design moderno e responsivo
- Catálogo de produtos esportivos
- Carrinho de compras funcional
- Seção de destaques
- Totalmente em HTML + CSS + JavaScript

## Como usar
1. Abra o arquivo `index.html` no navegador
2. Explore os produtos
3. Adicione itens ao carrinho

Desenvolvido com base no SisSenai, adaptado para loja esportiva.
